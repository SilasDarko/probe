# Benchmarks

GPU benchmark results pending hardware validation.

No benchmark in this repository has yet been run on NVIDIA hardware. This file
will record only real measurements, each with the exact GPU, driver, CUDA
version, Nsight versions, CPU, OS, compiler, optimization flags, workload size,
warmup and measured iteration counts, and timing methodology.

Results will come from the procedure in [docs/gpu-validation.md](docs/gpu-validation.md),
and only from a recorded run of it.
